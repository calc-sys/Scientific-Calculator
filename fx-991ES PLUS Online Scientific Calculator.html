How to use it like the real calculator

SHIFT

Tap SHIFT, then a key, to use the orange function printed above it. Example: SHIFT + sin gives sin⁻¹.

ALPHA and variables

Tap ALPHA, then a key with a red letter above it. ALPHA + hyp types C, ALPHA + CALC types =. To store a result press SHIFT + RCL (STO) and then the letter key. To recall, press RCL and then the letter key.

MODE

Tap MODE to choose COMP, CMPLX, STAT, BASE-N, EQN, MATRIX, TABLE, VECTOR or GRAPH. On a keyboard, press 1 to 9 to pick from the list.

SETUP

Tap SHIFT then MODE for angle unit, fraction style, Fix / Sci / Norm, engineering notation and complex format.

SOLVE, CONST, CONV, CLR

Type an equation with X (ALPHA + ) types X, ALPHA + CALC types =). Press SHIFT + CALC, the screen says Solve for X, then press = to get X and L−R. SHIFT + 7 is CONST (01–40). Type a number, then SHIFT + 8 and a two-digit code for CONV (01–40). SHIFT + 9 is CLR.

Keyboard

Type digits, letters and function names such as sin( directly. Enter calculates, Backspace deletes, Esc clears, Shift + P types π.
